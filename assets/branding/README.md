# KD Favicon

Generated using the built-in image generation tool. `kd-mark.png` is the original,
unaltered output. `kd-mark-light.png` is the selected black-on-white edit, also
created with the built-in image tool. Run `node scripts/prepare-favicon.mjs` to export the 16/32/48px
ICO, 192px browser icon, and 180px Apple touch icon. Next.js discovers the exported
files in `app/` automatically.

## Color Edit Prompt

Edit the supplied KD favicon only by reversing its color treatment. Preserve the exact existing letter shapes, weight, spacing, proportions, centered placement, and square canvas. Change the white "KD" letters to solid black #171511 and change the dark background to uniform pure white #ffffff. Flat two-color finished logo, with clean antialiased edges. No new elements, no typography redesign, no texture, no shadows, no gradients, no border, no presentation mockup. The final output must be the same KD mark, now black lettering on white.

## Generation Prompt

Use case: logo-brand. Create one finished square favicon logo for Kar Dhillon's personal website. Exact text: "KD" (uppercase K followed by uppercase D). A bold, compact, expertly balanced geometric sans-serif monogram, visually compatible with a General Sans Bold uppercase wordmark. Two clearly recognizable upright letters, tightly spaced but not overlapping, thick strokes and open counters that survive reduction to a 16px browser tab icon. Flat white lettering on a uniform near-black #171511 square background. The monogram occupies approximately 80% of the canvas width and 65% of the canvas height, precisely optically centered. Strong simple shapes, generous D counter, no hairlines. Minimal, restrained, architectural, timeless. Single final asset only, square 1024x1024. No mockup, no grid of variations, no presentation board, no extra text, no tagline, no outlines, no gradients, no shadows, no texture, no ornament, no three-dimensional effects, no framing outside the square. Edge-to-edge solid near-black background.
